# Customer Behavior Analysis

## Project Overview

This project analyzes customer purchasing behavior using an e-commerce dataset.

The analysis focuses on:
- Data cleaning and preprocessing
- Feature engineering
- Customer purchase behavior
- RFM-based customer segmentation
- Purchase and revenue patterns
- Customer churn and retention
- Business recommendations

## Dataset

The dataset contains 250,000 customer transactions with information such as:
- Customer ID
- Purchase Date
- Product Category
- Product Price
- Quantity
- Total Purchase Amount
- Payment Method
- Customer Age
- Returns
- Gender
- Churn

## Methodology

1. Data Cleaning
2. Feature Engineering
3. Exploratory Data Analysis
4. RFM Customer Segmentation
5. Churn and Retention Analysis
6. Business Insights and Recommendations

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files

- `Customer_Behavior_Analysis.ipynb` – Complete analysis and visualizations
- `Customer_Behavior_Analysis_Report.pdf` – Project report

## Key Objective

The main objective is to understand customer behavior and identify actionable strategies to improve customer retention, engagement, and business performance.

## Recommendations

- Retain high-value customers
- Reduce customer churn
- Improve new customer conversion
- Reduce product returns
- Use personalized marketing strategies
